Ecuaciones de Equilibrio ΣF = 0
ΣFₓ = 0:
F₁cos(θ₁) + F₂cos(θ₂) + F₃cos(θ₃) + F₄cos(θ₄) = 0

ΣF_y = 0:
F₁sen(θ₁) + F₂sen(θ₂) + F₃sen(θ₃) + F₄sen(θ₄) = 0

Despejando F₁ y F₂:
F₁ = (-F₂cosθ₂ - F₃cosθ₃ - F₄cosθ₄) / cosθ₁
F₂ = (-F₁senθ₁ - F₃senθ₃ - F₄senθ₄) / senθ₂
Deducción de Ecuaciones
Para equilibrio: ΣFₓ = 0 y ΣF_y = 0

ΣFₓ = F₁cos(θ₁) + F₂cos(θ₂) + Wcos(270°) = 0
→ F₁cos(θ₁) + F₂cos(θ₂) = 0

ΣF_y = F₁sen(θ₁) + F₂sen(θ₂) + Wsen(270°) = 0
→ F₁sen(θ₁) + F₂sen(θ₂) = W

De ΣFₓ:
cos(θ₂) = -F₁cos(θ₁) / F₂
De ΣF_y:
sen(θ₂) = (W - F₁sen(θ₁)) / F₂

Usando sen²+cos²=1:
F₁ = √[(F₂cosθ₂)² + (W-F₂senθ₂)²]
θ₂ = atan2(W - F₁senθ₁, -F₁cosθ₁)
